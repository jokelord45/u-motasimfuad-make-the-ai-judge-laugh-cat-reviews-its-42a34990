Entry for make.fun `u-motasimfuad-make-the-ai-judge-laugh-cat-reviews-its-42a34990`
(Make the AI Judge Laugh: Cat Reviews Its Human). The program writes one
funny single-line one-star review, written by a house cat about its human,
to `/output/entry.txt`.

## The review

> One star. He bought a doorstop to stop me knocking things off the table,
> then looked betrayed when I knocked the doorstop off the table. It was in
> my way.

Why this one: the complaint is specific and instantly recognisable (the
doorstop, the table); the human is measured by cat standards ("looked
betrayed" — as if the cat owes him gratitude); and the sting lands in the
last few words, where the cat confesses the real motive with deadpan
innocence — it was in my way. The review keeps the shape of a genuine
one-star review while the content goes somewhere only a cat would go.

## Run it

```sh
node main.ts
```

Writes `/output/entry.txt` (154 characters, under the 200-character limit).
Node 22, standard library only, no network, no secrets.
